# LM Soluções · landing page

Site institucional da LM Soluções, softhouse de Belém do Pará, publicado no GitHub Pages.

- HTML, CSS e JS puros, sem build: `index.html`, `styles.css`, `app.js`
- Contatos em `app.js` → `CONTATO` (WhatsApp e Instagram)
- O formulário monta a mensagem, copia para a área de transferência e abre o Direct do Instagram (`ig.me/m/lm.solucoes_`)
- Ícones de tecnologia: [Simple Icons](https://simpleicons.org) (CC0)

Rodar localmente: `python3 -m http.server 8090` e abrir http://localhost:8090
